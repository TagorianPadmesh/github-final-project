
# Simple Interest Calculator

## Overview

This project demonstrates the use of Git and GitHub for version control while building a simple Bash calculator.

## Formula

Simple interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal:** Initial amount of money.
* **Rate:** Annual interest rate in percentage.
* **Time:** Duration in years.

## Technologies Used

* Bash scripting
* Git
* GitHub

## Usage

Run the `simple-interest.sh` script in a Bash-compatible terminal. Enter the principal amount, annual interest rate, and time period when prompted.

## Learning Objectives

* Understand Git repositories and branches.
* Practice committing and pushing changes.
* Learn how to collaborate using GitHub.
* Develop a basic calculator using Bash.
